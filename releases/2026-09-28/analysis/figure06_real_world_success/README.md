# 真机成功率柱状图

数据来自用户提供的四组 π0.5 / ActMem-VLA 成功率，每种方法每项任务 20 次：

|任务|π0.5|ActMem-VLA|
|---|---|---|
|R1：拿起放下碗两次，再按按钮|17/20 = 85%|20/20 = 100%|
|R2：称芒果|2/20 = 10%|13/20 = 65%|
|R3：按三次按钮，然后向左摆|3/20 = 15%|7/20 = 35%|
|R4：拿起放下碗三次，再按按钮|6/20 = 30%|11/20 = 55%|

R 编号用于区分 LIBERO-Mem 的 T 编号。图中每根柱子标注成功率，一位小数；不额外添加百分号，因为纵轴已经说明单位。

沿用此前配色与透明度：π0.5 #0072B2，ActMem-VLA #009E73，alpha=0.84。
PDF 为单栏宽 88.9 mm，文字对应 LaTeX 正文 10 pt（数学下标按数学排版缩小）。外围留白已最小化；保留刻度和任务标签所需空间。

运行：`python plot_real_world_success.py`

若实际模板栏宽不同：`python plot_real_world_success.py --width-mm 实际栏宽毫米值`

插入 PDF 使用 `\includegraphics[width=\columnwidth]{fig06_real_world_success.pdf}`。

四任务宏平均：π0.5 35.0%，ActMem-VLA 63.75%，差值 28.75 个百分点。此处是单组试验的成功率统计，不是三训练种子的均值或标准差。
