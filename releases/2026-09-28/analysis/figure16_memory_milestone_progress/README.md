# 球面记忆：任务节点进度版

## 修改

- 单色由浅绿到深绿，表示0%–100%的任务节点进度。
- 百分比 = 已到达的必要操作节点数 / 该任务必要节点总数；每个节点等权，不再使用归一化时间。
- G1、G2…表示第几次抓取（用抬起物体参考帧作为可观察节点）；P1、P2…表示对应放置。
- 每任务五条示范分开，关键节点按各示范的事件位置对齐；交互版可选节点、播放、旋转并查询具体百分比。
- 保留figure15的球面坐标，仅改变标签、颜色和播放控制，没有移动记忆点或重新拟合。

## 依据与边界

从原A100 HDF5提取五条示范的夹爪闭合/松开动作及抬起和放置后画面，保存在 `evidence/`。逐条核对原动作SHA256与记忆提取清单，保证节点与记忆来自同一示范。G使用闭合到松开期间末端高度最大的观察帧；P使用松开动作后的第一个边界，结合松开后画面确认放置。它们是用于事后分析的操作定义，不是精确接触检测时间。

根据原图，T4的demo_2首次闭合未抬起瓶子，排除该候选周期；T10的demo_5第二次候选周期未完成篮子搬运，作为额外重抓而不增加所需搬运进度。两条示范的原始记忆点仍全部保留，重试期间进度不增加。具体排除和全部事件见 `progress_annotations.json`。

任务分别含2、2、6、6、10、14、6、8、4、4个必要节点。T9/T10的四个节点依次对应取奶酪、放入篮子、取目标篮子、放置目标篮子；G/P编号按操作顺序编号。

百分比是人工定义的等权节点完成度，不是连续真实进度，也不是模型预测。标签仅用于绘图，没有用于训练或PCA。没有强迫同一阶段聚类。

记忆每20步采样。关键节点附着于事件之后第一个已有记忆点，最多延后19步；若两个节点落在同一采样区间，可以映射到同一记忆点。静态图只标G节点避免拥挤，交互节点菜单及悬停包含G/P。若最后一个节点晚于最后一次记忆采样，不人为补出100%的记忆点。

球面弧线仍只是插值。进度相同的一段弧线使用同一颜色；跨节点弧线使用后一个端点的颜色，不把时间插值改称进度测量。

## 文件

- `memory_milestone_progress.html`：离线交互图。
- `fig16_milestone_progress_10pages.pdf`：逐任务PDF，每页五条示范及说明。
- `individual/Txx_milestone_progress.pdf/png/svg`：各任务独立图。
- `coordinates/Txx_progress.npz`：原球面坐标、节点进度、查询位置、示范索引。
- `milestone_candidates.json`、`evidence/`：原记录与证据图。
- `milestones.csv`、`progress_annotations.json`：实际事件位置、投影采样点和百分比。
- `plot_memory_progress.py`、`prepare_viewer.py`：绘图及交互模板生成脚本。

```powershell
python .\prepare_viewer.py
python .\plot_memory_progress.py
```
